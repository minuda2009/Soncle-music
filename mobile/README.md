# Soncle for Android (0.1.0, first build)

The Android app shares its code with the desktop app:
- **the UI** (`../renderer`): unchanged, plus a phone stylesheet (`src/mobile.css`);
- **the audio engine**: limiter, LUFS normalisation, EQ, crossfades, Flow radio;
- **the YouTube layer** (`../src/yt.mjs`).

The only Android-specific code is `src/backend.js`. It provides the same `window.api` that the
desktop preload provides, and it is built with [Capacitor](https://capacitorjs.com).

## Build the APK (Android Studio)

You need Node.js 20+ and Android Studio (it brings the Android SDK and JDK 21).

```bash
cd mobile
npm install          # Capacitor, plugins, youtubei.js, esbuild
npm run sync         # builds www/ and copies it into android/
npm run open         # opens android/ in Android Studio
```

Then, in Android Studio:
- **Run ▶** puts it on a phone with USB debugging turned on.
- **Build → Build App Bundle(s) / APK(s) → Build APK(s)** gives you
  `android/app/build/outputs/apk/debug/app-debug.apk`.

After any change to `../renderer`, `../src` or `mobile/src`, run `npm run sync` again.

## How it works

| Piece | Desktop | Android |
| --- | --- | --- |
| Network | Electron `net.fetch` | CapacitorHttp: native requests, no CORS, custom User-Agent allowed |
| Audio source | `mstream://` proxy | `src/mse.js`: a MediaSource filled with 1 MB range requests, fetched back to back |
| Stream clients | YTMUSIC+PO token, IOS, ANDROID_VR, WEB+PO token, TV, WEB_EMBEDDED | IOS, ANDROID_VR, TV, WEB_EMBEDDED (no BotGuard window for PO tokens) |
| Storage | `%APPDATA%\Soncle\*.json` | the same JSON files in the app's private storage (Capacitor Filesystem) |
| Media keys | Windows media overlay | a native MediaSession: notification, lock screen and headset buttons. It runs as a foreground service, so playback continues in the background. |
| Back button | — | closes the open sheet, then goes back a page, then sends the app to the background |

## Not in 0.1.0 yet

- **Sign-in.** Google blocks sign-in inside apps. The plan is a Custom Tab sign-in, as on desktop
  with a real browser.
- **Downloads and offline play.**
- **Local music files.**
- **Per-device sound profiles.** Android audio-device detection isn't wired up yet.
- **Smart ducking, mini player, tray, Discord.**

The settings for these are hidden on the phone rather than shown broken.

## Files

- `src/backend.js`: the Android `window.api`: storage, streaming, lyrics, media session, the back
  button.
- `src/mse.js`: the chunked MediaSource player.
- `src/mobile.css`: the phone layout:
  - search on top;
  - a mini player above the bottom navigation;
  - full-screen Now playing and queue.
- `build.mjs`: copies `../renderer` to `www/`, bundles the backend, and adjusts `index.html`:
  - adds the viewport;
  - adds `'unsafe-eval'` to the CSP, because youtubei.js deciphers stream URLs with generated code.
- `tools/android-icons.mjs`: launcher icons and splash screens, drawn from
  `../assets/soncle-icon.svg`.
- `android/`: the Android Studio project. It was generated by Capacitor; `MainActivity.java`, the
  manifest and the theme have been edited.
